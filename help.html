Cardtridge™ turns physical things into game cartridges. Scan a printed card, tap an NFC card, or plug in a USB stick or memory card, and the game it stands for starts on this PC. It works with your installed Steam, GOG and Epic games, and runs in the system tray.

Only installed games can be launched. A game that's launched twice within 10 seconds starts once, so a card that's read twice doesn't open two copies.

The games page

Click the tray icon to open it. Every installed game is shown with its art; GOG and Epic games carry a badge.

  • Find a game: the search icon (Ctrl+K), the letters, and the store filter. The slider sets the card size.
  • Game buttons: hover the round button at the top right of a game for Play, Show QR code, Choose the printed art and Print this card.
  • Linked cards show under the game's name. A wave icon is an NFC card; a card icon is a USB stick, SD card or CF card. Click × to unlink one.
  • New games appear when Cardtridge starts, when a drive is plugged in, or when you pick Rescan games in the tray menu.

Steam games start through Steam. GOG games start their own exe. Epic games start through the Epic Games Launcher, so you may need to be signed in to it. Cardtridge brings GOG and Epic games to the front once their window opens.

Linking a card to a game

NFC cards, USB sticks, SD cards and CF cards are all linked the same way:

  1. Open the games page.
  2. Put the NFC card on the base, or plug in the stick or card.
  3. An orange banner says New card … — click a game to link it. Games that already have a card move to the end.
  4. Click the game. From now on, that card launches it.

A new card waits 2 minutes to be linked. Press Esc or click Cancel to forget it. Each card launches one game, but a game can have as many cards as you like. Unlinking a card and inserting it again lets you link it to a different game.

Links are kept in %APPDATA%\cardtridge\cards.json, so they stay on this PC. On another PC, cards need linking again.

NFC cards

NFC cards are read by a Disney Infinity base: the Wii and PlayStation versions, which show up as USB device 0E6F:0129. The Xbox 360 base can't be used. Plug the base in any time; the tray menu shows whether it's connected.

Most NFC stickers, cards and key fobs work, as do Disney Infinity figures and discs. Phones, watches and bank cards don't, because they show a different ID every time they're read.

The pad under a card lights up:

GreenThe linked game is launching.
OrangeA new card, waiting to be linked on the games page.
RedThe card couldn't be read, or its game isn't installed.

The base reconnects by itself after the PC sleeps.

USB sticks, SD and CF cards

A USB stick, SD card or CF card can be a cartridge without anything installed on it. Plug it in, link it, and from then on plugging it in launches the game from this PC. The drive only carries an ID.

  • The ID is the drive's volume serial number, which is set when it's formatted. Formatting the drive gives it a new ID, so it has to be linked again.
  • Cards formatted by a camera often all share the serial 0000-0000. Cardtridge then gives the card its own ID by writing a small hidden file, cardtridge-id, to it. Leave the file there; deleting it makes the card new again. A card that's locked (the switch on the side of an SD card) can't be given an ID.
  • Card IDs start with SD- whichever kind of drive they're on.
  • External SSDs and hard drives that Windows treats as fixed disks can't be linked; they can still launch a game installed on them.

Drive launching can be turned off in Settings under USB drives.

Installing a game on the drive

If you need the extra storage, a drive can hold the game itself. Plugging it in then launches the game installed on it, with no linking needed.

  1. In Steam, open Settings → Storage, add a library on the drive, and install one game to it.
  2. Plug the drive in. Cardtridge adds the game to the list and launches it.
  • Only Steam games work this way. A drive with more than one game is left alone.
  • Steam remembers the library by its drive letter, so the drive has to come back as the same letter. If it doesn't, assign it a fixed letter in Windows' Disk Management.
  • A linked card launches its linked game, even if it also has a game installed.
Performance will be what it is. The game loads from the drive, so it's only as fast as the drive and the port. An external SSD on USB 3 is close to an internal drive. USB sticks are slower, and SD and CF cards slower still, which shows as long loading screens and stutter in games that stream from disk. Small or older games are the best fit. Don't remove a drive while its game is running; the game will crash and may lose its save.

Card readers

SD and CF card readers are flaky at best. Cardtridge launches a card as soon as Windows sees it, so when a card doesn't launch, it's almost always because Windows hasn't seen it yet.
  • Eject cards before removing them. Use Eject in File Explorer or Safely remove hardware in the taskbar. Pulling a card out can corrupt it, and a reader can stop noticing new cards after a card is pulled mid-read.
  • If the reader stops seeing cards, reset it: unplug the reader from the USB port, wait a few seconds, and plug it back in. Use a port on the PC itself rather than a hub if it keeps happening.
  • Some cards take a few seconds to appear. Windows has to read the card before it gets a drive letter, and slow, large or nearly full cards take longer. Cards with a damaged file system can take much longer, or Windows may offer to scan and fix them.
  • Older readers can't read newer cards. Cards over 32 GB are SDXC, and many older readers, including some SanDisk ImageMate models, don't support them. The reader's light may come on while Windows shows nothing.
  • Readers with several slots show a drive letter for each slot even when it's empty. That's normal.

To check whether it's the reader or Cardtridge, look for the card in File Explorer. If File Explorer doesn't show it, Cardtridge can't either.

QR codes and phones

Each game's QR code is a web link to this PC. Scanning it with a phone opens the link, and the game starts on the PC. The phone needs to be on the same network, and Windows Firewall has to let the connection through; the first time Cardtridge runs, Windows asks, and you should allow private networks.

The link includes this PC's address, its port and a secret key, so a code only works for this PC. If the PC's address or the port changes, printed codes stop working. Give the PC a fixed address in your router, and reprint cards after changing either in Settings. Check address and port in Settings tests both with your phone.

Barcode scanners

A QR barcode scanner can launch games without a phone. Set it to serial mode (SPP) and pair it with Windows over Bluetooth. Cardtridge connects to paired devices whose name contains scan or barcode, and the tray menu shows when it's connected. For other names, or a scanner on a USB COM port, change the scanner settings in Settings.

A scanner reads the QR codes Cardtridge prints, steam://rungameid/… links, and bare game IDs.

Printing cards

Cardtridge prints cards to slide into sleeves or stick on NFC cards. Choose the template, sides and options in Settings:

  • Templates: Avery 28877 and 5371 business cards, credit card size, trading card size, top loader size, and LabelLife 3 × 2 in thermal labels.
  • Side A is the game's art and logo; side B has its details and tags, with the QR code if it's turned on. Print both, one or the other, or both on one sheet to cut out and glue back to back.

On the games page, the print button in the nav prints every game shown. Ctrl+click games to select them and print just those, or use Print this card on one game.

Choose the printed art picks side A's image from the store's art, screenshots or your own upload (drop an image on the window). Drag and zoom to choose the crop, and turn the logo on or off. Quality badges show whether the image is sharp enough at the printed size.

The tray icon

Cardtridge runs in the system tray. Closing its window hides it; it keeps launching games. Click the icon to open the games page, or right-click it for the menu:

  • The NFC base and scanner status.
  • Open QR page, Settings…
  • Rescan games: look for games installed or removed since Cardtridge started.
  • Open log folder: the log of everything Cardtridge has done, useful when something doesn't work.
  • Check for updates, Start with Windows, and Quit.

FAQ and troubleshooting

I inserted a card and nothing happened.
  • Check that the card shows in File Explorer. If it doesn't, see Card readers: eject cards properly, reset the reader, and make sure the reader supports the card.
  • Open the games page; if the card isn't linked yet, the orange banner should be waiting for you to pick a game.
  • Check that USB drives is on in Settings.
  • Look in the log (Open log folder in the tray menu) for a card … inserted line.
A card I linked before is showing up as new.

The card was formatted, which gives it a new ID, or its hidden cardtridge-id file was deleted. Link it again, and unlink the old ID from its game.

Two of my cards launch the same game, but I only linked one.

They share an ID, which happens when one card was copied (cloned) from the other. Format one of them, then link it again.

My card says "Not installed" or the NFC pad turns red.

The linked game was uninstalled, or it's on a drive that isn't plugged in. Install it, or plug the drive in, and pick Rescan games if it still isn't found.

My phone can't reach the PC when I scan a code.
  • Put the phone on the same Wi-Fi as the PC, not mobile data or a guest network.
  • Run Check address and port in Settings, and allow Cardtridge through Windows Firewall on private networks.
  • If the PC's address changed, the printed codes point at the old one; give the PC a fixed address and reprint.
A game started behind my other windows.

Windows only lets the app you're using bring a window to the front. Cardtridge does this for GOG and Epic games once their window appears; Steam usually does it for its own games. Click the game in the taskbar if it doesn't come forward.

Can I use a USB stick on a PC without Cardtridge?

No. Windows no longer runs programs from USB drives automatically, so Cardtridge has to be running on the PC to notice the stick.

Cardtridge says it's already running.

Only one copy runs at a time. Look for its icon in the system tray; it may be under the arrow that shows hidden icons.

Where does Cardtridge keep its files?
  • Settings, card links, print settings and uploaded art: %APPDATA%\cardtridge
  • The log and cached game details: %LOCALAPPDATA%\cardtridge
